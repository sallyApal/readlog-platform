ReadLog Project 
Documentation & Requirements
1. Project Overview & IdeaReadLog is an all-in-one Arabic-first web platform designed to merge book reading, daily habit tracking, and progress analytics into a seamless digital experience. It transforms reading intentions into lasting daily routines by connecting a personal library manager with interactive habit-building tools.   
2. Functional RequirementsAuthentication System: Secure user registration, login, and logout with complete form validation and security measures.Multi-Page Architecture: A Python Django-powered web application consisting of at least 5 main pages:   Login/Registration pagePersonal Library page (with status filtering and search)Daily Habits tracker pageAnalytics & Visualization pageAbout Us pageResponsive Design: Fully responsive layout across desktop and mobile screens utilizing Bootstrap 5 (RTL optimized).Dynamic Interactivity (AJAX): Real-time habit check-ins and updates without page reloads.   Cloud Deployment: Production-ready application deployed on an AWS EC2 cloud instance utilizing Nginx and Gunicorn.
3. Database Design & ERD (Entity-Relationship Modeling)Models Implementation:User (Managed via Django’s built-in authentication system)Book: Stores title, author, category, total pages, pages read, status (Want to read, Currently reading, Completed), rating, and review.Habit: Stores habit name, description, start date, start/end time, duration type, color tag, and active status.HabitLog: Tracks daily completions and historical progress.ERD Configuration: Relational database tables structured via Django ORM (SQLite/PostgreSQL) with properly defined primary and foreign keys.
4. Wireframes & Visual DesignDesign Platforms: Designed using tools like Figma, Balsamiq, or MockupWorld.Key UI/UX Standards:Global font family: Cairo.Sticky navigation bar with layered background imagery (navbook.jpg).Grid-based library cards and clean, minimalist layout structures.Custom brand visuals including logo_readlog.jpg, girl_read.png, and habit.png.
5. Development Roadmap & Project Timeline
Day 1: Requirements Document, ERD Design, Wireframing, GitHub Repository setup, and Trello Board task initialization.
Day 2: Backend Implementation (Django Models, Database Setup, and Migrations).
Day 3: Front-End Implementation, UI styling (Bootstrap 5 RTL), AJAX integration, and initial Alpha version deployment.
